# OctoAcme Project Management Documentation

## Overview
OctoAcme follows a structured, customer-first approach to project management with clear roles, iterative delivery, and data-informed decisions. This documentation hub provides guidance for all project phases—from initiation through retrospective and continuous improvement.

1. Start with the [Project Management Overview](./octoacme-project-management-overview.md) to understand core principles and lifecycle
